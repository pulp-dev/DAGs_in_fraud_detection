# Использование AI-агента в работе

Работа выполнялась с помощью Claude Code (CLI-агент Anthropic, модель Claude Opus) в одной сессии в терминале.
Агент читал код, писал и правил файлы, запускал команды и Docker.

Агент помогал исправлять ошибки в коде, редактировать описанные функции, объяснял непонятные места.
Агент помог проанализировать первоначальный код:
- описал, за что отвечает каждый сервис, DAG и модуль `pipeline/`;
- нашел скрытые проблемы, которые не видны при обычном запуске:
  - окно обучения могло сдвинуться дважды, если сбой происходил между заменой `current.parquet` и записью `training_state`;
  - повтор задачи дозаписи батча задваивал строки в витрине;
  - ранняя остановка шла по test-месяцу, поэтому метрики на test были завышены;
  - признак `year` вне обучающего диапазона: поток идет с текущей датой, а модель учится на 2019 годе;
  - стартовая модель несовместима с новым набором признаков.

Агент помогал тестировать правки:
Логику окна и split агент проверил на синтетических данных с заглушкой вместо БД, в том числе повторный запуск.

Агент помогал сравнивать версии модели во время реализации препроцессинга: запускал обучения и подсчитывал метрики, выводил удобный отчет.

Агент реализзовал 9 правил в виде SQL-агрегатов, HTML-отчет с атомарной публикацией для DAG `data_quality`

Агент использовался для написания README с указанием всех необходимых инструкицй.
